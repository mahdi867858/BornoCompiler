Live Product Syntax: Intuitive, Expressive & 100% Functional

Real source code executing directly inside our compiler engine from examples/valid_full_demo.brn.

valid_full_demo.brn — Borno Production Source
# ভেরিয়েবল ঘোষণা ও টাইপ বাইন্ডিং
ধরি সংখ্যা বয়স = ২০;
ধরি বাক্য নাম = "মাহদি";

# শর্তাধীন লজিক্যাল ব্রাঞ্চিং
যদি (বয়স >= ১৮) {
    দেখাও(নাম);
}
নাহলে {
    দেখাও("অপ্রাপ্তবয়স্ক");
}
🔍
Production Language Constructs
  • ✓ ধরি সংখ্যা / ধরি বাক্য: Explicit static type bindings (Numbers & Strings).
  • ✓ যদি / নাহলে: Clean structured conditional branching with mandatory block scopes.
  • ✓ দেখাও(...): Universal native standard console output.
  • ✓ ২০, ১৮ (০-৯): Authentic Bengali numerals verified natively by NumberHelper.

Core Engine: Passes 1 & 2 🎤 Speaker: Sharon Shahrin Mim

High-Performance Unicode Lexer & LL(1) Precedence Parser

Deep script handling and recursive descent engineering implemented from scratch.

🔍
Phase 1: Unicode Lexical Scanner
  • ✓ Unicode Block \u0980-\u09FF: Complete support for Bengali characters, vowel diacritics (কার), and conjuncts (যুক্তবর্ণ).
  • ✓ NumberHelper Engine: Converts Bengali numerals (০-৯) directly into 64-bit machine double values.
  • ✓ Strict Script Validation: Rejects ASCII English digits with clear error coordinates to avoid mixed-script errors.
📐
Phase 2: LL(1) Recursive Descent Parser
  • ✓ Precedence Climbing: Handles arithmetic precedence: () > * / % > + - > == != > <.
  • ✓ Left-Recursion Free: Iterative grammar loops handle left-associative operators without stack overflow.
  • ✓ Panic-Mode synchronize(): Discards invalid tokens until statement boundaries to catch multiple errors.
Core Engine: Passes 3 & 4 🎤 Speaker: Sharon Shahrin Mim

Phase 3 & 4: Abstract Syntax Tree & Scoped Semantic Scoping

Constructing the structural hierarchy and enforcing rigorous compile-time type safety.

🌳
Phase 3: OOP AST Hierarchy

8 polymorphic node classes implement the unified ASTNode interface, rendered via ASTPrinter:

• ProgramNode
• DeclarationNode
• AssignmentNode
• IfNode
• PrintNode
• BinaryExpr
• LiteralNode
• VariableNode
🛡️
Phase 4: Scoped Semantic Analysis
  • ✓ Parent-Pointer Symbol Table: Hierarchical scopes support block nesting and safe variable shadowing.
  • ✓ Static Type Safety: Enforces numeric operations on সংখ্যা, string concatenation on বাক্য.
  • ✓ Div-by-Zero Intercept: Detects constant division by zero (১০ / ০) at compile-time before execution.
