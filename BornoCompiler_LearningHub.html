🔥 VIP EXAMINER DEFENSE · JUMANA (M1) Lexer.java ➔ advance() & line tracking

👨‍🏫 প্রশ্ন: লেক্সারের advance() মেথডে Newline পেলে line++ করি। তাহলে ২য় লাইনে গেলে কি position = 0 হয়ে যায়? নতুন লাইনে position = 0 কেন করা লাগে না?

🎯 সরাসরি ১-লাইনের পাঞ্চ উত্তর (পরীক্ষককে যা বলবেন):
"না স্যার, নতুন লাইনে গেলে position কখনোই ০ হয় না! কারণ position হলো পুরো সোর্স ফাইলের গ্লোবাল ক্যারেক্টার অফসেট (Global Character Index: 0 থেকে শেষ পর্যন্ত)। নতুন লাইনে গেলে শুধুমাত্র line++ বাড়ে এবং col = 1 রিসেট হয়, কিন্তু position একটানা সামনে (0, 1, 2, ... N) বাড়তেই থাকে।"
❌ যদি position = 0 করা হতো তবে কী মারাত্মক সমস্যা হতো?
১ম লাইন শেষ করে Enter চাপার পর যদি position = 0 করে দিতাম, তাহলে লেক্সার আবার পুরো সোর্স কোডের একদম ১ম ক্যারেক্টারে ফেরত চলে যেত! ফলে কম্পাইলার একটি অসীম লুপে (Infinite Loop) আটকে গিয়ে ক্র্যাশ করত এবং ২য় লাইনে কখনোই যেতে পারত না।
💡 Enter ক্যারেক্টার কীভাবে প্রসেস হয়?
সোর্স কোড মেমোরিতে একটি একক দীর্ঘ ক্যারেক্টার স্ট্রিম। কোডে আমরা যখন Enter চাপি, তখন মেমোরিতে সেটি একটি নির্দিষ্ট ক্যারেক্টার \n (ASCII 10) হিসেবে থাকে। advance() প্রতি ক্লিকে position++ করে এই \n কে পড়ে এবং পরের লাইনের ১ম ক্যারেক্টারে চলে যায়।
src/lexer/Lexer.java ➔ advance() Method Proof
private void advance() {
    // ১. position সবসময় ১ ঘর করে সামনে বাড়ে (কখনোই ০ হয় না!)
    position++; 

    if (position >= source.length()) {
        currentChar = '\0'; // EOF (সোর্স কোডের শেষ)
    } else {
        currentChar = source.charAt(position);
        
        // ২. নিউলাইন ('\n') পেলে শুধুমাত্র লাইন নম্বর বাড়ে ও কলাম রিসেট হয়
        if (currentChar == '\n') {
            line++;  // লাইন ১ বাড়ল
            col = 1; // কলাম রিসেট হয়ে ১ হলো (পজিশন কিন্তু বাড়তেই থাকবে!)
        } else {
            col++;
        }
    }
}
🌐 Bangla Unicode & NumberHelper Architecture

BornoCompiler বাংলা বর্ণমালার জন্য জাভার চার-লেভেল ফিল্টারিং আর্কিটেকচার ব্যবহার করে:

// 1. বাংলা ডিজিট ইউনিকোড রেঞ্জ (০-৯ = ০ - ৯)
public static boolean isBanglaDigit(char c) {
    return c >= '০' && c <= '৯';
}

// 2. বাংলা বর্ণমালা রেঞ্জ ও ZWNJ (‌), ZWJ (‍)
private boolean isBanglaChar(char c) {
    return (c >= 'ঀ' && c <= '৿') || c == '‌' || c == '‍';
}

// 3. বাংলা বর্ণ (সংখ্যা ব্যতীত)
private boolean isBanglaLetter(char c) {
    return isBanglaChar(c) && !NumberHelper.isBanglaDigit(c);
}

"না স্যার, নতুন লাইনে গেলে position কখনোই ০ হয় না! কারণ position হলো পুরো সোর্স ফাইলের গ্লোবাল ক্যারেক্টার অফসেট (Global Character Index: 0 থেকে শেষ পর্যন্ত)। নতুন লাইনে গেলে শুধুমাত্র line++ বাড়ে এবং col = 1 রিসেট হয়, কিন্তু position একটানা সামনে (0, 1, 2, ... N) বাড়তেই থাকে।"
❌ যদি position = 0 করা হতো তবে কী মারাত্মক সমস্যা হতো?
১ম লাইন শেষ করে Enter চাপার পর যদি position = 0 করে দিতাম, তাহলে লেক্সার আবার পুরো সোর্স কোডের একদম ১ম ক্যারেক্টারে ফেরত চলে যেত! ফলে কম্পাইলার একটি অসীম লুপে (Infinite Loop) আটকে গিয়ে ক্র্যাশ করত এবং ২য় লাইনে কখনোই যেতে পারত না।
💡 Enter ক্যারেক্টার কীভাবে প্রসেস হয়?
সোর্স কোড মেমোরিতে একটি একক দীর্ঘ ক্যারেক্টার স্ট্রিম। কোডে আমরা যখন Enter চাপি, তখন মেমোরিতে সেটি একটি নির্দিষ্ট ক্যারেক্টার \n (ASCII 10) হিসেবে থাকে। advance() প্রতি ক্লিকে position++ করে এই \n কে পড়ে এবং পরের লাইনের ১ম ক্যারেক্টারে চলে যায়।
src/lexer/Lexer.java ➔ advance() Method Proof
private void advance() {
    // ১. position সবসময় ১ ঘর করে সামনে বাড়ে (কখনোই ০ হয় না!)
    position++; 

    if (position >= source.length()) {
        currentChar = '\0'; // EOF (সোর্স কোডের শেষ)
    } else {
        currentChar = source.charAt(position);
        
        // ২. নিউলাইন ('\n') পেলে শুধুমাত্র লাইন নম্বর বাড়ে ও কলাম রিসেট হয়
        if (currentChar == '\n') {
            line++;  // লাইন ১ বাড়ল
            col = 1; // কলাম রিসেট হয়ে ১ হলো (পজিশন কিন্তু বাড়তেই থাকবে!)
        } else {
            col++;
        }
    }
}

src/parser/Parser.java ➔ synchronize()
private void synchronize() {
    advance();
    while (!isAtEnd()) {
        if (previous().getType() == TokenType.SEMICOLON) return;
        switch (peek().getType()) {
            case DHORI: case SONGKHA: case BAKKA:
            case JODI: case DEKHAO: case JOTOKKHON:
                return; // স্টেটমেন্ট বাউন্ডারি পাওয়া গেছে
        }
        advance();
    }
}

public class SymbolTable {
    private final Map<String, Symbol> symbols = new HashMap<>();
    private final SymbolTable parent; // প্যারেন্ট স্কোপ পয়েন্টার

    public SymbolTable(SymbolTable parent) {
        this.parent = parent;
    }

    // লেক্সিক্যাল স্কোপ অনুযায়ী চলক অনুসন্ধান
    public Symbol lookup(String name) {
        if (symbols.containsKey(name)) return symbols.get(name);
        if (parent != null) return parent.lookup(name);
        return null;
    }
}
